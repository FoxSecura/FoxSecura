# Code de conduite

FoxSecura veut maintenir un espace de contribution sérieux, accueillant et sûr. Ce code s'applique aux issues, pull requests, revues, discussions et autres espaces officiels du projet.

## Comportements attendus

Les contributeurs et mainteneurs sont invités à :

- discuter des idées et du code, pas attaquer les personnes ;
- formuler des critiques précises, techniques et actionnables ;
- accepter les désaccords sans agressivité ;
- respecter le temps et les limites des autres contributeurs ;
- signaler clairement les incertitudes, risques et conflits d'intérêts pertinents ;
- protéger les informations sensibles rencontrées dans le cadre du projet ;
- privilégier la sécurité des utilisateurs et serveurs Discord lors des décisions techniques.

## Comportements inacceptables

Sont notamment interdits :

- harcèlement, menaces, intimidation ou attaques personnelles ;
- propos discriminatoires ou dégradants ;
- publication d'informations personnelles sans consentement ;
- spam, trolling persistant ou perturbation volontaire des discussions ;
- pression pour obtenir une fusion, un accès ou une décision ;
- divulgation publique volontaire d'un secret ou d'une vulnérabilité exploitable avant coordination raisonnable ;
- falsification de résultats de tests, de preuves ou d'informations de sécurité.

## Revues de code

Une demande de changement n'est pas une attaque personnelle. Une revue peut refuser une solution qui fonctionne si elle augmente inutilement la surface d'attaque, la complexité, les dépendances ou le coût de maintenance.

Les mainteneurs doivent, autant que possible, expliquer les décisions techniques et appliquer les mêmes standards à leurs propres contributions.

## Signalement

Pour un problème de comportement, contactez un mainteneur du projet par un canal GitHub approprié sans publier de données personnelles supplémentaires. Si le signalement implique également une vulnérabilité ou un secret, suivez en priorité [`SECURITY.md`](SECURITY.md) et évitez toute issue publique contenant les détails sensibles.

Les signalements doivent être examinés de façon confidentielle dans la mesure du raisonnable. Les informations ne doivent être partagées qu'avec les personnes nécessaires au traitement du problème.

## Mesures possibles

Selon la gravité et la répétition, les mainteneurs peuvent :

1. demander une correction du comportement ;
2. mettre fin à une discussion ou verrouiller un fil ;
3. refuser ou fermer une contribution ;
4. limiter temporairement la participation ;
5. exclure durablement une personne des espaces du projet.

Une menace crédible, une fuite intentionnelle de données sensibles ou un harcèlement grave peut justifier une mesure immédiate sans avertissement préalable.

## Portée

Ce code protège la collaboration sur FoxSecura. Il ne vise pas à imposer des opinions personnelles en dehors des espaces ou activités directement liés au projet.
