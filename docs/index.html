Défense en profondeur

Cinq moteurs. Une seule stratégie.

Chaque famille possède une responsabilité claire. Les primitives communes restent partagées pour éviter les doublons et les compteurs concurrents.

Lancer FoxSecura localement

Le dépôt épingle ses versions principales pour garder un environnement reproductible. Activez aussi Server Members Intent dans le Discord Developer Portal.

git clone https://github.com/FoxSecura/FoxSecura.git
cd FoxSecura
export DISCORD_TOKEN="votre_token"
cargo check
cargo test
cargo run

OpenAI · omni-moderation-latest

AI Moderation utilise exclusivement le endpoint Moderations d'OpenAI. Le provider classe le contenu mais ne peut jamais appliquer directement une sanction Discord.

export OPENAI_API_KEY="votre_cle_api"
# endpoint: https://api.openai.com/v1/moderations
# model: omni-moderation-latest

i18n · EN / FR / DE

FoxSecura garde un catalogue typé et centralisé. Les variantes Discord comme en-US, fr-FR ou de-DE sont résolues automatiquement sans multiplier les fichiers par langue.

Modèle de sécurité

Les moteurs produisent des signaux et décisions typés. La détection reste séparée des effets de bord Discord. Pour l'IA, le provider ne reçoit aucun objet Discord et ne retourne jamais une sanction.

FAQ

Questions fréquentes.

Les réponses importantes sur la philosophie et l'état actuel de FoxSecura.

FoxSecura est-il prêt pour la production ?

Pas encore. Les moteurs et leurs tests sont avancés, mais le branchement complet aux événements Discord, la configuration persistante et les actions finales sont encore en cours.

Pourquoi Rust ?

Pour une base performante, sûre, explicite et maintenable, adaptée au travail concurrent d'un bot de sécurité.

L'IA peut-elle bannir directement un membre ?

Non. Le provider IA classe le contenu. Les règles FoxSecura décident ensuite de la conséquence et la couche action reste séparée.

Quelles langues sont prises en charge ?

Anglais, français et allemand. Les variantes de locale Discord sont résolues automatiquement.

Puis-je contribuer ?

Oui. Le dépôt est public sous AGPL-3.0-only. Les changements doivent rester ciblés, testés et cohérents avec l'architecture.
