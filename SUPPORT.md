# Support FoxSecura

Ce dépôt distingue les bugs, les propositions, la documentation et les problèmes de sécurité afin de garder les échanges exploitables.

## Avant d'ouvrir une issue

Consultez d'abord le [Wiki FoxSecura](https://github.com/FoxSecura/FoxSecura/wiki), notamment les pages d'installation, de configuration et de développement.

## Ouvrir une issue

Utilisez les formulaires GitHub :

- **Bug** : comportement incorrect ou régression reproductible ;
- **Amélioration** : nouvelle fonctionnalité ou évolution ciblée ;
- **Documentation** : information manquante, ambiguë ou obsolète.

Pour accélérer le diagnostic, fournissez un scénario minimal, la branche ou le commit concerné et uniquement les logs utiles après suppression des données sensibles.

## Vulnérabilités et secrets

N'utilisez pas une issue publique pour une vulnérabilité exploitable, un token, une clé API ou tout autre secret. Consultez [`SECURITY.md`](SECURITY.md).

## Ce que le support ne garantit pas

FoxSecura est développé par des contributeurs. L'ouverture d'une issue ne garantit ni délai de réponse, ni délai de correction, ni support individuel d'une infrastructure d'hébergement tierce.

Les demandes suffisamment documentées, reproductibles et limitées à FoxSecura sont plus faciles à traiter efficacement.
